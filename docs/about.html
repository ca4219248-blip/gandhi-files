About this archive

Public Records Archive is a small, independent index of public documents. Each entry points to the original record — a court order, an audit report, a parliamentary answer, a gazette notification or a published report — and gives the reader the source so they can check it themselves.

What gets published

  • A record is listed only if the document itself is attached or linked, and its source is stated.
  • The summary on a record describes what the document says. It does not add a conclusion.
  • Records are written in neutral language. No adjectives about people, no motive, no verdict.
  • Drafts stay private. Only published records are visible, and files are served through short lived links.

What does not get published

  • Material that is not traceable to a document.
  • Private information about individuals — addresses, phone numbers, family details, health, minors.
  • Content that is abusive, threatening or aimed at a community.
  • Anything whose publication a court has restrained.

Right of reply and corrections

Anyone named in a record can send a reply, a correction or a clarification through the right of reply form. Replies that address the document are published on the record's page. If a factual error is shown, the record is corrected and the correction is noted. If a document turns out to be withdrawn, superseded or restrained, the record is unpublished.

Disclaimer

This site republishes documents; it does not investigate, accuse or conclude. Being named in a public document is not a finding of guilt. An allegation of a criminal offence is established only by a competent court, and every accused person is presumed innocent until then. Nothing here is legal advice.

How this site is built

This is the static, read-only build, served by GitHub Pages. Records live in a Postgres database and the PDFs in a private storage bucket; the page you are reading can only see records that are published, because the database enforces that for anonymous visitors. Editing happens in a separate admin panel, which runs on the PHP deployment of the same project and is not part of this static build.

Contact
